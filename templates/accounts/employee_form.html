Architecture Notes
  • User Linking: A Django auth_user login account is automatically connected to this Employee profile.
  • Password Security: Passwords are encrypted using standard PBKDF2/SHA256 password hashing before being saved.
  • Atomic Transactions: User and Employee records are created inside an atomic block, so if either fails, no partial record is kept.
  • Standard Access: Newly created employees have standard access; administrator privileges (is_staff) are not granted by default.
